## 阅读指引

### 三类依据标签

| 标签 | 含义 |
|------|------|
| ✅ 国标依据 | 国家标准 / 行业标准有明确条文对应 |
| 🔶 工程经验 | 李Sir 工程案例积累，无国标直接对应 |
| ⚠️ 待核实 | 规则存在但依据未完整核实 |

### 局限声明读法

「局限声明」字段记录每条规则的**已知边界和已知缺口**。
存在局限声明 ≠ 规则不可用。意义在于：知道自己站在什么地基上。

### 关于 Rw 与 Rw+Ctr 的说明（重要）

本白皮书及系统代码层均以 **Rw（计权隔声量）** 表述隔声目标值。

国标及地方规范（GB 50118、GB 55038-2025、DB11/1740-2020 等）对交通噪声场景的外窗要求，
普遍采用 **Rw+Ctr** 形式（计权隔声量 + 交通噪声频谱修正量）。
Rw+Ctr 比 Rw 低 3~5 dB，差距来自交通噪声低频成分的修正。

**v1.0 处置方式（文案层，不动规则层）：**
招标文件中的隔声条款采用以下格式：
> 「外窗计权隔声量 Rw ≥ X dB。第三方检测报告应同时列出 Rw+Ctr 值
> （交通噪声频谱修正量），Rw+Ctr 通常较 Rw 低 3~5 dB。」

此格式使用户在验收时知道**应看两个值而不是一个值**，是对冲口径错配的主要手段。
规则层切换为 Rw+Ctr 计算的决策见附录 A-5（议题 3 子案例 C）。

### 内容话术建议读法

供内容运营 Project 消费的参考表述。原则：
- 用李Sir第一人称工程视角，不用系统语言
- 主动说明工程经验性质，不回避、不夸大
- 用户看完后信任度应上升，而不是对工具产生怀疑

### A-1 · 距离修正的声学逻辑链条缺口

**涉及规则：** `Rw.dist.lt20` / `Rw.dist.gt50`

**当前处置：** 规则保留；basis 维持 `empirical_rule`；局限声明已更新（正文）。
